## Overview

This repository contains the full implementation and written report for a recommender system study conducted on the **MARS (Mandarine Academy Recommender System)** dataset — a real-world, publicly available e-learning corpus published on Harvard Dataverse. The study was undertaken as **Part 2 of the Data Mining course (24ASD513)** at Amrita Vishwa Vidyapeetham, Coimbatore.

Four recommendation paradigms are implemented, evaluated, and compared:

| # | Method | Similarity / Technique | Cold-Start Handling |
|---|--------|------------------------|---------------------|
| 1 | User-Based Collaborative Filtering | Cosine similarity | Popularity fallback |
| 2 | User-Based Collaborative Filtering | Pearson (mean-centred cosine) | Popularity fallback |
| 3 | Content-Based Filtering | TF-IDF on item metadata | Native (no user history needed) |
| 4 | Matrix Factorisation | Mean-centred Truncated SVD (k=20) | — |

### Key Results at a Glance

| Metric | Value |
|--------|-------|
| SVD RMSE (test set, 1–10 scale) | **2.2678** |
| Precision@5 | **0.0708** |
| Recall@5 | **0.0179** |
| User–item matrix sparsity | > 99% |
| Dataset size | 85,339 explicit ratings · 1,451 items |

## Dataset

The MARS dataset was published by Farah et al. (2022) and is hosted on **Harvard Dataverse** under Creative Commons Attribution 4.0 (CC BY 4.0).

> Farah, M., Hobeika, A., & Issa, J. (2022). *MARS: Mandarine Academy Recommender System Dataset*. Harvard Dataverse. https://doi.org/10.7910/DVN/BMY3UD

Two files from the **French-language platform** are used in this study:

| File | Rows | Columns | Description |
|------|------|---------|-------------|
| `explicit_ratings_fr.csv` | 85,339 | 5 | `user_id`, `item_id`, `watch_percentage`, `created_at`, `rating` |
| `items_fr.csv` | 1,451 | 12 | `item_id`, `name`, `Difficulty`, `type`, `duration`, and more |

### Rating Derivation

Ratings are **not** manually assigned. Each rating is derived deterministically from the user's watch percentage:

```
rating = floor(watch_percentage / 10)
```

Watching 100% of a video yields a rating of **10**; watching 30% yields a **3**. This produces a strongly left-skewed distribution with a dominant peak at 10, which is a central modelling challenge of this dataset.

> **Note:** The data files are not included in this repository due to their size. Download them directly from Harvard Dataverse using the link above, and place them in the `data/` directory as described in [Quickstart](#quickstart).

## Methods

### 1. User–Item Matrix Construction

A user–item rating matrix is built using `pandas.pivot_table` with missing entries filled as zero. Matrix sparsity is computed as:

$$\text{sparsity} = 1 - \frac{|\text{observed ratings}|}{n_u \times n_i}$$

### 2. User-Based Collaborative Filtering — Cosine Similarity

Cosine similarity is computed between all user rating vectors:

$$\text{sim}_{\cos}(u, v) = \frac{\mathbf{r}_u \cdot \mathbf{r}_v}{\|\mathbf{r}_u\| \|\mathbf{r}_v\|}$$

Recommendations are generated by aggregating weighted scores from the top-10 most similar neighbours. A **popularity-based fallback** is triggered for users who have rated nearly all items.

### 3. User-Based Collaborative Filtering — Pearson Similarity

Pearson correlation is implemented as cosine similarity on a **mean-centred** rating matrix. For each user $u$:

$$\tilde{r}_{ui} = \begin{cases} r_{ui} - \bar{r}_u & \text{if } r_{ui} > 0 \\ 0 & \text{otherwise} \end{cases}$$

Mean-centring removes rating-scale bias (a key property of MARS, where users frequently give 9–10 out of obligation), producing monotonically declining and more discriminative similarity scores relative to flat cosine profiles.

### 4. Content-Based Filtering — TF-IDF

Item features (`Difficulty`, `type`, `name`) are concatenated into a single content string per item. `TfidfVectorizer` is applied and item–item cosine similarity is computed over the resulting TF-IDF vectors. Recommendations for a query item are the top-N most similar items in feature space.

### 5. Matrix Factorisation — Truncated SVD

1. **Mean-centre** the training matrix per user.  
2. Apply **Truncated SVD** with $k = 20$ components:

$$\tilde{R} \approx U_k \Sigma_k V_k^\top$$

3. Reconstruct full predicted ratings:

$$\hat{R} = U_k \Sigma_k V_k^\top + \bar{r}$$

4. Evaluate on an 80/20 held-out test split (random state 42) using **RMSE**, **Precision@5**, and **Recall@5** (relevance threshold: rating ≥ 7).

## Results

### Rating & Activity Distribution

- Ratings cluster strongly at **10**, with intermediate values (4–7) rare — a direct consequence of the watch-percentage derivation.
- User activity follows a **long-tail distribution**: a small cohort of power users account for a disproportionate share of ratings; most users rated fewer than 5 items.

### Cosine vs. Pearson Comparison (User 30, 15 rated items)

| Metric | Cosine | Pearson |
|--------|--------|---------|
| Top-1 similarity score | 0.42 | 0.27 |
| Rank-20 similarity score | 0.30 | 0.15 |
| Score range (top 20) | 0.12 | 0.12 |
| Shape of decline | **Flat** | **Monotone** |

Despite identical absolute range, the shapes differ qualitatively. Cosine assigns near-equal weight to all 20 neighbours — diluting the recommendation signal. Pearson concentrates weight on the most genuinely similar users, making it the appropriate measure for this dataset.

### SVD Evaluation

| Metric | Value | Interpretation |
|--------|-------|----------------|
| RMSE | 2.2678 | Within the 2.0–3.5 benchmark range for sparse e-learning datasets |
| Precision@5 | 0.0708 | ~1 in 14 recommended items was liked by the user |
| Recall@5 | 0.0179 | Top-5 recommendations captured ~1.8% of all liked items |

Low Precision/Recall values are structurally expected: (a) after an 80/20 split, most users have 1–2 test ratings, making ranking the one correct item from 1,350+ candidates extremely difficult; (b) SVD is trained to minimise RMSE — a rating prediction objective — not ranking quality.

## Limitations and Future Work

- **SVD variant**: `TruncatedSVD` (deterministic decomposition) is used here as a conceptual demonstration. Production-grade systems would employ **FunkSVD** or **SVD++** (stochastic gradient descent with user/item bias terms), which directly minimise observed rating error and typically achieve lower RMSE.
- **Content features**: The `Theme`, `Job`, and `Software` metadata columns are largely empty in the French dataset, limiting content-based discriminability to item name and difficulty level.
- **Future directions**:
  - Learning-to-rank objectives (e.g., Bayesian Personalised Ranking loss)
  - Incorporation of implicit feedback (`implicit_ratings_fr.tab`)
  - Neural Collaborative Filtering (NCF) architectures
  - Hybrid models combining collaborative and content signals
